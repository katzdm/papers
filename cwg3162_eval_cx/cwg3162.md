## Wording

Modify [expr.const]/31 as follows:

::: std
::: addu
During an evaluation _V_ ([intro.execution]) of an expression, conversion, or initialization _E_ as a core constant expression, the _point of evaluation of E during V_ is the program point _P_ defined as follows:

- [31.1]{.pnum} If _E_ is a potentially-evaluated subexpression of a default member initializer _I_, and _V_ is the evaluation of _E_ in the evaluation of _I_ as an immediate subexpression of a (possibly aggregate) initialization, then _P_ is the point of evaluation of that initialization. [For example, _E_ can be an immediate invocation in a default member initializer used by an aggregate initialization appearing at _P_.]{.note}
- [31.2]{.pnum} Otherwise, if _E_ is a potentially-evaluated subexpression of a default argument _A_ ([dcl.fct.default]), and _V_ is the evaluation of _E_ in the evaluation of _A_ as an immediate subexpression of a function call ([expr.call]), then _P_ is the point of evaluation of that function call.
- [31.3]{.pnum} Otherwise, _P_ is the point at which _E_ appears.
:::

[The _evaluation context_ is a set of program points that determines the behavior of certain functions used for reflection ([meta.reflection]).]{.rm} During the evaluation _V_ of an expression _E_ as a core constant expression, the [evaluation context]{.rm} [_evaluation context_]{.addu} of an evaluation _X_ [([intro.execution]) consists of the following points]{.rm} [during _V_ is the set _C_ of program points determined as follows]{.addu}:

::: rm
- The program point _EVAL-PT(L)_, where _L_ is the point at which _E_ appears, and where _EVAL-PT(P)_, for a point _P_, is a point _R_ determined as follows:
  - If a potentially-evaluated subexpression ([intro.execution]) of a default member initializer _I_ appears at _P_, and a (possibly aggregate) initialization during _V_ is using _I_, then _R_ is _EVAL-PT(Q)_ where _Q_ is the point at which that initialization appears.
  - Otherwise, if a potentially-evaluated subexpression of a default argument ([dcl.fct.default]) appears at _P_, and an invocation of a function ([expr.call]) during _V_ is using that default argument, then _R_ is _EVAL-PT(Q)_ where _Q_ is the point at which that invocation appears.
  - Otherwise, _R_ is _P_.
:::

- [31.4]{.pnum} [If the execution of _X_ occurs during the evaluation _Y_ of a manifestly constant-evaluated expression that is not _E_, then _C_ is the evaluation context of _X_ during _Y_.]{.addu}
- [31.5]{.pnum} [Otherwise, _C_ contains:]{.addu}
  - [31.5.1]{.pnum} [the point of evaluation of _E_ during _V_ and each synthesized point in the instantiation context thereof and]{.addu}
  - [31.5.2]{.pnum} [Each]{.rm} [each]{.addu} synthesized point corresponding to an injected declaration produced by any evaluation [executed during _V_ that is]{.addu} sequenced before _X_ ([intro.execution]).

[[The evaluation context determines the behavior of certain functions used for reflection ([meta.reflection]).]{.note}]{.addu}

::: addu
::: example
```cpp
struct S;
consteval std::size_t f(int p) {
  constexpr std::size_t r = /*Q*/std::meta::is_complete_type(^^S) ? 1 : 2;  // #1
  if (!std::meta::is_complete_type(^^S)) {
    std::meta::define_aggregate(^^S, {});
  }
  return (p > 0) ? f(p - 1) : r;
}

consteval {
  if (f(1) != 2) {
    throw;  // not evaluted
  }
}
```

During each evaluation of `std::meta::is_complete_type(^^S)` at #1 ([meta.reflection.queries]) that is executed during the evaluation of `f(1) == 2`, the evaluation context contains `Q`, but does not contain the synthesized point associated with the injected declaration of `S`. Control does not pass through the call to `std::meta::define_aggregate` during the evaluation of `f(0)`.
:::
